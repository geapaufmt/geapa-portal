# Current Portal convergence

This branch preserves the public Portal assets from Hosting a7b03bafe8fbad1e (26 October 2026). It must be reviewed with the matching canonical Core integration branch, not deployed over PROD automatically.

The only published stabilization change is the pending-label renderer/filter: object-shaped pendencies now display type/status instead of object coercion. The other runtime assets match the live frontend.

Public Firebase Web configuration and App Check site keys are client identifiers, not service-account credentials. Firebase generated /__/ initialization assets are not source. Nominal member/storage identity lists are deliberately omitted: these two adapters are closed in this review checkout, and must receive an independently approved private deployment overlay before any release. The PROD files are unchanged by that export. No private snapshots, evidence, personal records, access tokens or audit receipts are included.

The preview workflow skips integration/* branches to prevent a PR from publishing to the production project's Hosting. Production deployment remains manual and separately authorized. Other old root/legacy assets are preserved for review, not promoted as the runtime.
